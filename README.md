O1. Callbacks (Llamada de retorno)
Funcion que se pasa a otra funcion como
argumento, con la funcion de que la funcion
que receptora la ejecute (invoque) en algun
momento de su propio cuerpo.

1. Declarar una funcion: Definimos que hace
2. Invocar una funcion: Usamos paréntesis ()
para que corra ahora mismo.
3. Pasar como argumento: Usamos el nombre de la funcion
sin parentesis.

Callback asincrono y sincrono

sincrono: Para poder ejecutar inmediatamente dentro
de la funcion que lo resibe.

asincrono: Para ser ejecutado mas tarde.
